# MS-10 现场故障应急手册

| 项目 | 内容 |
| --- | --- |
| 日期 | 2026-11-15 |
| 原则 | 只读排查、最小修复、不清理数据库、不改安全配置 |
| 演示底线 | 数据库不可用时明确 BLOCKED，不伪造保存/列表成功 |

---

## 1. MySQL 无法连接

**可能原因：** 服务未启动、3306 被占用、端口/主机错误、口令错误、Schema 不存在。  
**只读检查：**

```powershell
Get-NetTCPConnection -LocalPort 3306 -State Listen -ErrorAction SilentlyContinue
```

**安全修复：** 由用户启动 MySQL、核对环境变量和 Schema。  
**禁止：** 本轮不得代启动/重启 MySQL；不得改账号/权限/配置；不得清库。  
**备用：** 用 MS-08 真实报告/截图演示解析与测试，明确保存/列表未执行。

---

## 2. 后端启动失败

**可能原因：** JDK 不是 17、Maven 依赖未下载、DB_PASSWORD 缺失、端口占用、jar 不存在。  
**只读检查：**

```powershell
java -version
mvn -v
Get-NetTCPConnection -LocalPort 8080 -State Listen -ErrorAction SilentlyContinue
```

**安全修复：** 使用 JDK 17；设置本机环境变量；用 `mvn -DskipTests package` 重新打包。  
**禁止：** 不要删除数据库/配置；不要改端口绕过问题。

---

## 3. 端口 8080 被占用

**只读检查：**

```powershell
Get-NetTCPConnection -LocalPort 8080 -State Listen |
  Select-Object LocalAddress,OwningProcess
Get-Process -Id <PID>
```

**安全修复：** 只停止自己启动的旧后端；无法确认归属时不要杀进程。  
**备用：** 用已有截图/报告；不要临时改 server.port 造成环境不一致。

---

## 4. 前端启动失败

**可能原因：** Node 未安装/版本过低、依赖缺失、5173 占用、`strictPort`。  
**只读检查：**

```powershell
node -v
npm -v
npm ls --depth=0
```

**安全修复：** 使用 Node 22；`npm install`；停止自己的旧 Vite。  
**禁止：** 不要删除 `node_modules` 后无法恢复；不要改代理到公网。

---

## 5. npm 依赖缺失

**可能原因：** 未执行 `npm install`、lock 与 package 不一致。  
**安全修复：** 在 `frontend` 执行 `npm install`，保留 lock。  
**备用：** 已构建的静态页面/截图；不现场改依赖版本。

---

## 6. 前端无法访问后端

**可能原因：** 后端未启动、Vite 代理失效、端口错误。  
**只读检查：** 浏览器 Network 面板；`Invoke-WebRequest http://127.0.0.1:8080/api/health`。  
**安全修复：** 启动后端、核对 `vite.config.ts` 的 127.0.0.1:8080。  
**禁止：** 不要把代理指向外部主机。

---

## 7. CORS 错误

**可能原因：** 绕开 Vite 代理直连 8080、生产域名不一致。  
**安全修复：** 开发期使用 Vite 同源代理 `/api`；不要为演示临时开放任意 CORS。  
**备用：** 使用代理地址演示。

---

## 8. 解析接口失败

**只读检查：** `/api/health`；请求体 `rawText` 是否非空、≤20000、有效行 ≤200；返回码/错误码。  
**安全修复：** 修正输入；不要改 Parser 规则迎合演示。  
**备用：** 用固定有效文本；展示已保存的解析截图，并注明历史证据。

---

## 9. 保存失败

**可能原因：** 数据库不可用、无效行未修正、超过 200 条、字段校验失败、重复提交。  
**只读检查：** 浏览器响应、`/api/health/db`、弹窗计数。  
**安全修复：** 修正无效行；确保 MySQL 可用；不要绕过服务端校验。  
**禁止：** 不要直接写 SQL 伪造保存成功。  
**备用：** 展示保存确认弹窗和 MS-08 报告，明确本轮 BLOCKED。

---

## 10. 页面数据为空

**可能原因：** 数据库为空、查询条件过窄、逻辑删除过滤、请求失败。  
**只读检查：** Network/响应 total；清空搜索；查看后端日志。  
**安全修复：** 用虚构数据或清空搜索；不要清库。  
**备用：** 用解析/静态页面演示。

---

## 11. 浏览器页面错乱

**可能原因：** 缩放、宽度、缓存、旧构建。  
**安全修复：** 100% 缩放、刷新、使用 Chrome/Edge；按 1366/1280 演示。  
**禁止：** 不要临场改 CSS 布局；用已有响应式证据。

---

## 12. 演示数据重复

**可能原因：** 多次保存同一批数据。  
**安全修复：** 重新加载页面、用不同虚构号码；不要批量 DELETE。  
**备用：** 用搜索过滤/只展示解析流程。

---

## 13. 数据库 Schema 不存在

**只读检查：** `SHOW DATABASES;`、`SHOW TABLES;`。  
**安全修复：** 由用户执行 `schema.sql` 建库；不要用测试 Schema 冒充正式库。  
**禁止：** 不要 DROP 后重建未知库。

---

## 14. 环境变量缺失

**症状：** 启动报 `DB_PASSWORD` 无法解析或连接失败。  
**安全修复：** 在当前 PowerShell 设置 `DB_URL/DB_USERNAME/DB_PASSWORD`，或使用本地未跟踪配置。  
**禁止：** 不要把口令写进 README/脚本/截图。

---

## 15. 现场网络不可用

**影响：** npm 安装、在线文档、外部 CDN 不可用。  
**安全修复：** 提前安装依赖、使用本机静态资源；不要依赖公网演示。  
**备用：** 用本地截图、报告、PDF 和已启动应用。

---

## 现场决策顺序

1. 先确认后端 `/api/health` 和前端页面；
2. 再确认数据库 `/api/health/db`；
3. 数据库不可用：只演示解析/架构/测试，保存/列表标记 BLOCKED；
4. 任何修复不得删除数据、改 MySQL/防火墙或提交 Git；
5. 记录实际命令、错误和退出码，不伪造成功。
