## 4. 现场启动

使用 `ms-10-reproduction-guide.md` 中固定的 JDK 17/Maven/Node 路径，先执行 `java -version` 和 `mvn -v` 确认不是系统默认 JDK 26。

```powershell
cd backend
mvn spring-boot:run
```

```powershell
cd frontend
npm run dev
```

MySQL 必须由用户提前准备；本阶段禁止代启动/重启。数据库不可用时，不得伪造保存/列表成功。
