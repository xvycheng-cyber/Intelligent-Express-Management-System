## 1. 原始项目目标

### 1.1 核心目标

实现一套本机课程演示用的**快递地址簿录入与管理系统**：

1. 多行文本集中输入；
2. 自动解析姓名、电话、地址；
3. 用户预览、人工修正、确认保存；
4. 地址簿分页/搜索/增删改/批量操作；
5. 覆盖课程任务书 2.1～2.20 的 Web 实践页和 Servlet 映射演示；
6. 用真实代码、测试、截图完成论文 2.21。

### 1.2 原始业务边界

范围内：

- 匿名单用户，无登录/权限；
- 地址簿三类业务字段：收件人姓名、电话、详细地址；
- 解析与保存分离；
- 逻辑删除；
- 分页 + 关键词；
- 批量保存/批量删除；
- Web 基础实践页 2.1～2.19；
- 2.18 线框仿制页；
- 2.20 Servlet URI 映射演示；
- 论文与截图。

范围外（原始规划已明确）：

- 注册/登录/权限；
- 快递下单/轨迹；
- 地图、地址标准化、行政区划库；
- OCR/语音/通讯录；
- Excel/CSV（P2）；
- AI 云解析（P2，默认关闭）；
- 多租户、审计、MQ、缓存、微服务；
- 移动端/小程序。

### 2.2 核心 BR/FR/NFR

原始规划中的已知核心规则：

- BR-01：一行一条，空行忽略但统计；
- BR-02：逗号/Tab/分号；
- BR-03：字段顺序灵活；姓名 1～50 码点；
- BR-04：地址保留原文；
- BR-05：解析/保存分离；
- BR-06：部分行失败不丢其他行；
- BR-07：行号 + rawLine；
- BR-08：预览可编辑；
- BR-09：批量保存全成功或全回滚；
- BR-10：逻辑删除；
- BR-11：批删校验；
- BR-12：服务端字段校验；
- BR-13：脱敏手机；
- BR-14：列表排序 + 字面 LIKE + 关键词码点；
- BR-15：Parser 纯逻辑；
- BR-16：日志脱敏；
- BR-17：无登录；
- BR-18：INVALID 不提交；
- BR-19：isEdited 派生、不入库；
- BR-20：仅本机；
- BR-21：批删仅当前页；
- BR-22：本机 root 连接、口令外置。

原始 FR：

- FR-01～FR-07：录入/解析/修正/确认保存/单条新增；
- FR-08～FR-14：列表/搜索/新建/编辑/删除/批删/列表状态；
- FR-15～FR-17：Web 基础页/线框页/Servlet 演示；
- FR-18～FR-21：统一异常/校验/敏感信息/策略扩展点；
- FR-22：导出（P2，不进 MVP）。

原始 NFR：

- 解析 100 行 ≤300ms（记录，不预设）；
- 列表万级分页 ≤500ms（记录）；
- 最多 20000 字符 / 200 有效行 / 200 条批量保存；
- Chrome/Edge 最近两个大版本；最小 1280×720；不要求移动端；
- 所有写操作反馈；破坏性操作确认；
- SQL 参数化、LIKE 转义、无堆栈、密钥外置、仅本机；
- 分层、TypeScript 严格、无 `any` 滥用；
- 批量事务；
- 无 Redis/MQ/搜索引擎/鉴权框架。

## 4. 原始技术方案

### 4.1 后端

- Spring Boot 3.3.5 / Java 17；
- Controller → Service → Mapper；
- Parser 独立、无 Mapper/JDBC；
- MyBatis-Plus BaseMapper + 关键词分页 XML；
- 逻辑删除；
- `R{code,message,data}`；
- `data.violations[]` 与 `items[].errors[]` 分层；
- 批量事务；
- 仅 127.0.0.1；
- root 本机演示，口令环境变量。

### 4.2 前端

- Vue 3 + TS + Vite + Element Plus；
- `/import` 录入；
- `/addresses` 管理；
- `src/api` 统一封装；
- `toPayload` 投影；
- `Array.from` 姓名计数；
- 分页字段 number、ID string；
- 仅当前页批量选择。

### 4.3 数据库

- 单表 `express_address`；
- `id BIGINT`、`receiver_name VARCHAR(50)`、`phone VARCHAR(20)`、`full_address VARCHAR(255)`；
- `create_time/update_time` DB 默认；
- `is_deleted TINYINT`；
- 索引 `idx_deleted_create`、`idx_phone`；
- 无外键/唯一/触发器；
- 初始化 `schema.sql`、`data.sql`、可选 `admin-init.sql`。

### 4.4 测试

原始计划：

- L1 Parser 单测；
- L2 Controller MockMvc；
- L2 真实 Parser + HTTP；
- L3 MySQL 集成；
- L4 Playwright/浏览器；
- 安全/性能/截图；
- MS-08 全量 R1～R5。
