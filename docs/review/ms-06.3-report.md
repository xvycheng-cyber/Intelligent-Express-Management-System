## 2. 2.1～2.5 每个知识点的实现说明

### 2.1 行内显示类型 inline

文件：`frontend/src/components/basics/InlineDemo.vue`

- 多个真实 `<span>` 在同一行排列；
- 可修改文本、元素数量、字号；
- 可设置尝试 width/height、上下/左右 padding、边框、上下/左右 margin；
- 可修改文字色、背景色、边框色；
- “填入长文本”观察自然换行；
- 紧凑行高对照 span 使用固定 12px 上下 padding、3px 上下边框，放大垂直重叠现象；
- 代码区由当前参数实时生成；
- 重置恢复默认。

**准确性说明**：

- 普通非替换行内元素的 `width`/`height` 不参与布局，演示中仍将值写入 style，但真实布局由内容决定；
- 水平 padding/border/margin 会推挤同一行文字；
- 垂直 padding/border 会绘制但通常不撑开行框，可能覆盖相邻行；
- 垂直 margin 不参与行内布局；
- 没有声称 inline 的所有盒模型属性都“完全无效”。

### 2.2 区块显示类型 block

文件：`frontend/src/components/basics/BlockDemo.vue`

- 真实 `<div>` 块级元素，不使用绝对定位模拟；
- 每个块独占一行；
- 默认 `width:auto` 填充包含块；
- 可切换固定宽度，调整宽/高；
- 可调整上下间距；
- 可切换水平居中 `margin-left/right:auto`；
- 可修改数量与背景色；
- 代码随参数变化；
- 重置。

### 2.3 行内区块显示类型 inline-block

文件：`frontend/src/components/basics/InlineBlockDemo.vue`

- 真实 `display:inline-block`；
- 宽高生效；
- 元素间保留真实空白字符，可开关；
- 可调容器宽度、元素数、宽、高、右外边距；
- 容器不足时由浏览器原生换行，不使用 Flex 或 JS 计算位置；
- 可切换 `inline` 对照，观察宽高失效；
- 代码、结论、重置。

### 2.4 弹性显示类型 flex

文件：`frontend/src/components/basics/FlexDemo.vue`

- 真实 `display:flex`；
- `flex-direction`（row / row-reverse / column / column-reverse）；
- `justify-content`（6 种）；
- `align-items`（5 种）；
- `flex-wrap`；
- `gap`；
- 项目数量；
- 容器宽度；
- 主轴/交叉轴可视化标签，随 direction 改变；
- 代码、结论、重置。

### 2.5 网格显示类型 grid

文件：`frontend/src/components/basics/GridDemo.vue`

- 真实 `display:grid`；
- `grid-template-columns` 四种模式：
  - `repeat(3, 1fr)`
  - `1fr 1fr 1fr`
  - `1fr 2fr 1fr`
  - `120px 1fr 1fr`
- `grid-template-rows: repeat(n, 58px)`；
- 列间距、行间距分别控制；
- 项目数；
- 首项 `grid-column: span 2`；
- 容器宽度；
- 代码、结论、重置。

## 4. 关键 CSS 与真实浏览器行为

### 2.1

```css
display: inline;
```

- 元素参与行内格式化上下文；
- 宽高对普通非替换 inline 元素不生效；
- 水平 margin/padding/border 实际占位；
- 垂直 padding/border 绘制但不撑开行框；
- 垂直 margin 不参与布局；
- 文本过长时按行内规则换行。

### 2.2

```css
display: block;
width: auto | 220px;
margin-left/right: auto;
```

- 块级元素独占一行；
- `width:auto` 填充包含块；
- 固定宽度 + `margin:auto` 居中；
- 相邻块 margin 在常规流中可能折叠（结论中说明，演示以间距/宽度为主）。

### 2.3

```css
display: inline-block;
```

- 像行内内容一样排列，但宽高生效；
- 元素之间的真实空白字符产生间隙；
- 容器不足时原生换行；
- 不用 flex/gap/JS 伪造。

### 2.4

```css
display: flex;
flex-direction; justify-content; align-items; flex-wrap; gap;
```

- Flex 是一维布局容器；
- 主轴随 `flex-direction` 改变；
- `justify-content` 沿主轴分配；
- `align-items` 沿交叉轴对齐；
- 页面标签同步显示轴方向。

### 2.5

```css
display: grid;
grid-template-columns;
grid-template-rows;
gap;
```

- Grid 是二维布局容器；
- `fr` 按可用空间比例分配，不是简单百分比；
- `repeat(3, 1fr)` 与三个 `1fr` 等价；
- `grid-column: span 2` 跨列。
