## 1. 页面结构

新增 `frontend/src/views/ServletDemoView.vue`：

1. 标题与学习目标；
2. “先容器，后 Spring”流程卡：
   - 精确 → 路径 → 扩展名 → 默认 `/`；
3. 容器映射 vs Spring MVC 对照；
4. 三种真实 Servlet 映射说明；
5. 真实请求矩阵：
   - 精确、精确不完全匹配、路径、扩展名、路径/扩展名冲突；
   - Spring MVC；
   - 精确 POST 405、Spring POST 405；
   - 默认 `/` 404；
   - 查询参数；
6. 单条执行 / 运行全部 / 清空；
7. 最近一次响应详情：
   - 方法/URL、状态、耗时、Content-Type；
   - `allow`、`x-demo-handler`、`x-demo-mapping-type`；
   - 真实响应正文；
8. 405/404/默认映射边界说明；
9. 底部容器链路提示。

页面没有使用固定命中结果、Mock 或本地模拟数据。

## 2. 真实 HTTP 请求

前端使用原生 `fetch`，见 `frontend/src/api/servletDemo.ts`：

- 保留非 2xx 状态；
- 保留响应头、正文；
- 8 秒超时；
- 网络错误显示为请求失败；
- 不经过 Axios `/api` 包装。

页面测试实际得到的服务器结果：

| 页面操作 | 结果 |
| --- | --- |
| 精确 GET | 200，`ExactMappingDemoServlet` |
| 路径 GET | 200，`PathMappingDemoServlet` |
| 扩展名 GET | 200，`ExtensionMappingDemoServlet` |
| Spring GET | 200，`ServletMappingDemoController` |
| 精确 POST | 405 |
| Spring POST | 405，body 含 `40501` |
| 默认 `/` 404 | 404，body 含 `40402` |
| 查询参数 | 200，仍为 Exact，body 含 `trace=query-42` |

405/404 均未被前端改成 200。

页面不会调用 `/api/addresses`；浏览器测试显式检查了 URL 列表。
